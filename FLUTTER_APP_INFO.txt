🔌 API ENDPOINTS UTILISÉS:
══════════════════════════════════════════════════════════════════

Base URL: https://k2mar-docuresume-backend.hf.space

Authentification:
• POST /users/register
• POST /users/login

Documents:
• POST /documents/upload (avec FilePicker)
• GET /documents/user/{userId}
• GET /documents/{documentId}/content
• DELETE /documents/{documentId}

IA Gemini:
• POST /generate/summary/gemini
• POST /query/gemini


🚀 LANCER L'APPLICATION:
══════════════════════════════════════════════════════════════════

1️⃣  INSTALLER LES DÉPENDANCES
    cd flutter_app
    flutter pub get

2️⃣  LANCER EN MODE DEBUG
    flutter run

3️⃣  LANCER SUR UN DEVICE SPÉCIFIQUE
    flutter devices
    flutter run -d <device-id>

4️⃣  BUILD APK RELEASE
    flutter build apk --release
    
    → APK généré dans: build/app/outputs/flutter-apk/
