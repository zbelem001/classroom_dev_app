# Manuel Utilisateur

Bienvenue dans l'application **DocuResume Pro**. Ce manuel vous guidera à travers les fonctionnalités principales.

## 1. Démarrage et Connexion

### Inscription
1. Lancez l'application.
2. Sur l'écran de connexion, tapez sur **"Créer un compte"**.
3. Remplissez votre **Email** et **Mot de passe**.
4. Validez.

### Connexion
1. Entrez vos identifiants.
2. Appuyez sur **"Se connecter"**.
3. *Note : Vous pouvez utiliser le mode démo si disponible.*

## 2. Tableau de Bord (Home)

L'écran d'accueil affiche la liste de vos documents importés.

- **Rafraîchir la liste** : Tirez la liste vers le bas (Pull-to-refresh).
- **Ajouter un document** : Appuyez sur le bouton **"+"** flottant en bas à droite.
- **Supprimer un document** : Appuyez sur l'icône **Corbeille** sur une carte document.

## 3. Gestion des Documents

### Importer un PDF
1. Cliquez sur le bouton **"+"**.
2. L'explorateur de fichiers de votre téléphone s'ouvre.
3. Sélectionnez un fichier **PDF** uniquement.
4. L'upload commence automatiquement. Une barre de progression peut s'afficher.

### Interagir avec un document
Cliquez sur n'importe quelle carte de document pour ouvrir l'interface de **Chat & Résumé**.

## 4. Chat IA et Résumés

Une fois sur le détail d'un document :

### Obtenir un Résumé
1. Appuyez sur l'onglet ou le bouton **"Résumé"**.
2. L'IA analysera le document et affichera les points clés.

### Poser des questions (Chat)
1. Tapez votre question dans la zone de texte en bas (ex: *"Quelles sont les compétences listées ?"*).
2. Appuyez sur le bouton **Envoyer**.
3. L'IA répondra spécifiquement sur le contenu de ce document.

## 5. Dépannage

- **Erreur de connexion** : Vérifiez votre connexion internet.
- **Upload échoué** : Vérifiez que le fichier est bien un PDF et qu'il ne dépasse pas la taille limite (10 Mo).
- **Problèmes d'affichage** : Essayez de redémarrer l'application.
